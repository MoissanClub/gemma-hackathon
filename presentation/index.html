The next level of generalization

A new request becomes
a new task program

def task(robot):
    cans = robot.look()
    if not cans:
        robot.say("No cans in view.")
        return
    target = max(cans,
                 key=lambda c: c["x"])
    if robot.pick(target["id"]):
        robot.give()

Illustrative task code over the shared API; the physical skills stay in the adapter
